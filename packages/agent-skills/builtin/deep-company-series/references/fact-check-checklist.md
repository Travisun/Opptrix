# 事实核查 Checklist

## 写前伪精确陷阱

1. 概率加权期望 → 只列情景+触发条件
2. 第三方 MAU/份额口径混乱 → 最多 2 个 anchor
3. 历史增速线性外推 → 禁止当承诺
4. 未公开持股 → 区间 +「不可知」
5. 强单一归因竞争对手失败 → 列多重原因

## 修订七项

1. 跨篇数字一致（市值/净利/持股）
2. 口径标注（Non-IFRS/GAAP/FCF）
3. 防双算（并表 vs 组合）
4. 横向比较同口径
5. 删概率加权
6. 弱化绝对化表述
7. 非财报数据带来源

## 抽检

定稿前对本 skill `scripts/report_audit.py extract` → 核验 → verdict。
