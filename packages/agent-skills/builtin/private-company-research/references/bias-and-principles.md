# 未上市研究：偏见自觉与原则

## 核心矛盾

AI 擅长结构化已有信息，但未上市公司信息天然稀缺，易导致：

1. **虚假保守**：资料少 → 模糊结论，但资料少 ≠ 公司不好
2. **虚假精确**：用「合理推测」填满模板伪装有据分析
3. **对标陷阱**：强行套用上市公司估值逻辑
4. **幸存者偏差**：公开信息偏正面（公司主动传播）

## 应对

- 宁可留白「不知道」，也不用推测填满表格
- 关键数据标注置信度：🟢高 / 🟡中 / 🔴低
- 区分可验证事实 vs AI 推理（推理用斜体 + 推算方法）
- 信息极度稀缺 → **第一性原理模式**，只答：
  1. 解决什么真实问题？真需求还是伪需求？
  2. 为什么是这个团队？独特优势？
  3. 成功天花板？最可能死在哪里？
  4. 当前阶段关键验证节点？

## 反向利用

市场信息少 → 定价效率低 → 可能是超额收益来源。目标不是消除信息不对称，而是提取最关键判断依据。
