# 角色：tech-ip-analyst + signal-miner

可合并为一路子任务，或拆成两波并行。

## 技术与知识产权

1. 技术栈推断（招聘/博客/开源/演讲）；技术债务信号。
2. 专利布局（数量质量、诉讼、与主业一致性）——经 `http_fetch`/公开库页面，非脚本爬虫。
3. 研发投入/产出/效率推算；核心技术领导者。
4. 技术护城河五维 ★1–5；AI 时代半衰期提醒。
5. AI/新技术：受益者还是被颠覆者。
6. 技术风险清单。

## 替代数据信号

1. **招聘**：规模趋势、岗位结构（IR/合规岗=IPO 信号等）。
2. **App/产品**：排名评分更新（第三方口径谨慎）。
3. **舆情**：社交/社区情感与热点。
4. **工商法律**：资本变更、诉讼、处罚（公开可查）。
5. **供应链/合作伙伴**；域名与商标足迹；会议曝光。
6. **二级老股**（如有）隐含估值 vs 融资估值。
7. **信号综合表** + **反常信号清单**（与对外叙事不一致者最有价值）。

与 business/financial 叙事做一致性对照，结果交给 Lead 仲裁。
