# 财报速读

## 何时使用

用户要对某标的的**财报/业绩**做快速解读，而不是全市场简报或完整尽调。

## 步骤

1. **确认标的与报告期**：明确股票与用户关心的季度/年度；不清时用选择题确认。
2. **激活基本面能力**：确保财务、利润表、资产负债表、现金流等工具可用。
3. **拉取核心表**：
   - 财务摘要（营收、净利润、同比等）
   - 按需：利润表 / 资产负债表 / 现金流量表
4. **交叉阅读**：对照概况中的主营业务与近期公告，解释数字变化的可能原因（标注为推断）。
5. **输出模板**：
   - 报告期与数据时效
   - 核心指标表（营收、毛利/净利、经营现金流等可用项）
   - 同比/环比亮点与恶化项
   - 需关注的风险或数据缺口
   - **不给出**买卖结论

## 注意

- 无数据时明确说「暂无该期财报数据」，禁止编造。
- 美股/港股与 A 股字段可能不同，按实际返回字段写，勿套用错误科目名。
