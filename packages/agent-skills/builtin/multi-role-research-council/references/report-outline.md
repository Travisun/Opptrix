## 目录

1. **标的与研讨元信息** — 代码、名称、数据时效、研讨轮次（辩论实际轮数）；**流程名须写「Opptrix投资研讨团流程」**（页眉/页脚同步）  
2. **研究问题** — 本次要回答的分析问题（非买卖问题）  
3. **分析师摘要** — 行情结构 / 基本面 / 资讯披露 / 资金情绪（事实要点）  
4. **多空辩论纪要** — 各轮核心攻防、让步与未决问题  
5. **研究主席立场** — 看多倾向 / 看空倾向 / 均衡 / 证据不足 + 支持与反对论据  
6. **风险互评** — 进取 / 中性 / 稳健：独立观点与交叉补充  
7. **事实｜推断｜缺口** — 三栏对照  
8. **后续观察清单** — 可验证触发条件与时间盒（非操作指令）  
9. **免责声明** — 使用下方固定全文
